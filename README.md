## 🚀 Projeto em destaque

### Pokédex

Aplicação desenvolvida com **Angular + Ionic**, consumindo a PokéAPI.

Principais recursos:

- Busca de Pokémon
- Paginação
- Tela de detalhes
- Favoritos persistidos localmente
- Layout responsivo para dispositivos móveis
- Testes unitários com Vitest
- Integração com Webhook
- Deploy automatizado na Vercel

🔗 [Acessar aplicação](https://pokedex-tays.vercel.app/home)
